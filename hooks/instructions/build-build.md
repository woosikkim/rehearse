## Build, then rerun

The ending is registered and confirmed; edits are open. Read the log, the fixtures and the ending first: they hold what the look found.

Build from the steps that worked: the same endpoints, headers and fields the look saw. Use what the scout found and write only the glue. Each failure seen by hand gets handling in the code. Write to the project's real files and the declared outputs, never to a copy, and run `rehearse run` when you expect it to pass. If the program runs but does not match the ending, carry on as a fix: find where its value is first made wrong.

**A thin source.** Never pad or invent data to make the ending pass. Report what was actually collected, and what is missing, in your final message.

**The stopping rule.** When `rehearse run` passes, stop: say so in your final message. The manager starts the director. If a note says edits are locked again, stop at once and say what you learned; the next look starts from there. If the director's findings are listed below, address each one.
